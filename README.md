## 原型标注

关联配置页与问卷报表页默认展开最右侧标注抽屉，说明对应功能的交互、统计口径及待确认事项。点击一条标注可定位并高亮对应元件；弹窗内的标注会先打开相应预览或选择窗口。标注定位不会提交关联、发起查询或下载文件。

抽屉支持“收起”，收起后从右侧“展开标注”恢复；鼠标停留或键盘聚焦标注时显示对应热区。标注只供阅读和定位。

## 直接打开

下载仓库ZIP、解压后双击根目录 `index.html`。无安装、构建或服务依赖，使用相对路径资源与示例数据。

按2026-10-09新确认，F04入口的问卷118展示4行分支明细：颜色/色差、颜色/褪色、造型/线条不流畅、空气动力学/L3空。F05入口保持首进空表，可输入118并点击查询；不带参数的报表入口也保持空表。

[Excel导出样例](downloads/association-export-sample.xlsx)包含25列、62道示例题目，每题一行。关联页的导出演示读取页面当前关联状态，生成UTF-8 CSV；Excel样例为固定参考文件。

## 规则与边界

- 配置统计：每层展示总题数、已配置、未配置；普通节点和系统保留节点完成关联都计已配置，仅勾选不计。
- 关联页只关联现有节点，不提供新增、编辑、删除节点功能。
- 全量逐题导出不受搜索或未展开分支影响；未配置上级下的题目仍保留完整题目路径；超出当前题目层级的列留空。
- 有实际L3回答的L2按每条L3输出明细，L2仅作为这些明细的上级信息，不额外生成L2父行；实际有回答但无L3的L2保留一行，L3～L5留空。按分支排序，答卷及评分汇总按实际对象去重。
- 明细数＝实际L3条数＋无L3但有回答的L2分支数。问卷118示例为3条L3＋1条L2，共4行；输出的L2行数不代表全部已答L2分支数。
- 查询暂按至少一个有效条件；默认树、默认全部状态不计条件。实际有效条件白名单待确认。
- 深层筛选只保留匹配的实际明细及其上级路径；有L3的分支即使全部子行被筛掉，也不能补造L2父行。是否有L3须依据筛选前的实际作答判断。
- L4/L5多回答、只到L1的答卷及未作答分支的处理待确认。
- 困扰度、最近发生时间的真实来源与归属待确认；静态示例暂展示在所属L3子行。
- 刷新、分页、导出使用上次已提交的查询结果；未提交草稿不影响当前结果。

仅为静态评审演示，全部数据为Mock，不接入真实答卷、节点库或业务后台，不代表SIT、生产或联调验收。
