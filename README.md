[打开在线原型](https://huanghaofa.github.io/tcs-requirements-prototypes/)

## 功能入口

| 编号 | 功能 | 原型入口 |
| --- | --- | --- |
| F01 | 层级题目配置统计 | [查看](pages/association.html?feature=F01) |
| F02 | 关联页移除节点维护 | [查看](pages/association.html?feature=F02) |
| F03 | 关联题目全量导出 | [查看](pages/association.html?feature=F03) |
| F04 | L2 与 L3 父子记录拆行 | [查看](report/index.html?feature=F04) |

首页按上述五项各提供一张卡片。前3项属于逻辑树关联配置页；后2项属于问卷报表明细页。

## 直接打开

下载仓库ZIP、解压后双击根目录 `index.html`。无安装、构建或服务依赖，使用相对路径资源与示例数据。

F04入口展示问卷118的6行父子记录；F05入口保持首进空表，可输入118并点击查询。任意打开不带参数的报表入口也保持空表。

[Excel导出样例](downloads/association-export-sample.xlsx)包含25列、62道示例题目，每题一行。关联页的导出演示读取页面当前关联状态，生成UTF-8 CSV；Excel样例为固定参考文件。

## 规则与边界

- 配置统计：每层展示总题数、已配置、未配置；普通节点和系统保留节点完成关联都计已配置，仅勾选不计。
- 关联页只关联现有节点，不提供新增、编辑、删除节点功能。
- 全量逐题导出不受搜索或未展开分支影响；未配置上级下的题目仍保留完整题目路径；超出当前题目层级的列留空。
- L2父行和L3子行均保留，按分支排序。答卷及评分汇总按实际对象去重。
- 查询暂按至少一个有效条件；默认树、默认全部状态不计条件。实际有效条件白名单待确认。
- 深层筛选保留匹配L3的L2父行，属于演示假设。
- L4/L5多回答、只到L1的答卷及未作答分支的处理待确认。
- 刷新、分页、导出使用上次已提交的查询结果；未提交草稿不影响当前结果。

仅为静态评审演示，全部数据为Mock，不接入真实答卷、节点库或业务后台，不代表SIT、生产或联调验收。
